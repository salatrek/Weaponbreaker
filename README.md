# Weaponbreaker

Мод Valheim про выбивание оружия при парировании и риск потерять оружие от сильного удара врага.

Основная концепция и текущие решения находятся в [DESIGN.md](DESIGN.md).

## Сборка

Нужны .NET SDK с поддержкой C# 10, установленный Valheim и профиль мод-менеджера с BepInExPack Valheim.

1. Скопируйте `Weaponbreaker.local.props.example` в `Weaponbreaker.local.props` рядом с `.csproj`.
2. Впишите `ValheimGamePath` — папку игры с `valheim_Data`, и `ValheimProfilePath` — папку профиля с `BepInEx/core`.
3. Перезагрузите проект в Rider и запустите сборку или выполните `dotnet build WeaponbreakerMod.sln`.

Локальный файл путей исключён из Git. Он подключается самим проектом, поэтому работает и в IDE, и в командной строке. Вместо файла можно задать переменные окружения `VALHEIM_GAME_PATH` и `VALHEIM_PROFILE_PATH` или свойства MSBuild `ValheimGamePath` и `ValheimProfilePath`. Для нестандартной структуры доступны свойства `ValheimManagedPath` и `BepInExPath`.

Сборка использует `BepInEx.dll`, `0Harmony.dll`, `UnityEngine.dll`, `UnityEngine.CoreModule.dll` и `assembly_valheim.dll` из указанных папок. При отсутствии DLL сборка сообщит, какой файл не найден.

## Реализация

Текущая реализация содержит BepInEx-каркас и боевые сценарии Weaponbreaker:

- Harmony-детектор получает только успешный `Humanoid.BlockAttack` в окне perfect block;
- сервис проверяет владельца ZDO врага, whitelist и шанс правила с учётом типа предмета, которым выполнено парирование;
- поддержанное оружие снимается с врага и создаётся как настоящий `ItemDrop`;
- для enemy-only оружия используется зарегистрированный fallback из `ObjectDB`;
- выпавший предмет получает сетевые маркеры Weaponbreaker и отключённый автосбор игроком.
- успешный блок или парирование щитом защищает оружие игрока от выпадения при этом ударе даже при остаточном уроне; блок оружием и сорванный блок щитом сохраняют шанс обезоруживания при потере здоровья.
- JSON-конфигурация содержит переключатели механик и значения шансов по врагам: вооружённые враги имеют два ползунка, безоружные — только шанс выбить оружие игрока;
- базовый шанс потери оружия у вооружённых врагов — 30%; навык оружия или щита изменяет итоговый шанс, нейтральная точка — 25;
- окно perfect parry остаётся ванильным; кулдауны настраиваются (враг — 8 секунд, подбор — 8 секунд, игрок — 15 секунд), настройки хоста применяются ко всем клиентам.

Расширение whitelist остаётся следующим вертикальным срезом.

Текущий код уже содержит эти пути: обратное выбивание проверяется после реального урона, скрытая атака из лука удваивает шанс выбивания врага, а AI врага возвращается к сохранённым координатам своего оружия. Предмет, выбитый из игрока, врагом не подбирается.
